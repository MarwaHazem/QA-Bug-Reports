# QA Bug Reports

This repository contains bug reports discovered during real-world application usage.

## What You'll Find

- Bug summaries
- Steps to reproduce
- Expected vs. actual results
- Severity and priority assessments
- Supporting evidence when applicable

## Confidentiality

All project details, company names, URLs, and sensitive information have been anonymized to maintain confidentiality and professional ethics.

## Skills Demonstrated

- Manual Testing
- Exploratory Testing
- Defect Reporting
- QA Documentation
